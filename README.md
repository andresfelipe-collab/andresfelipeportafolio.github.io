# Andres Gallego — Portfolio Audiovisual

Sitio estático (HTML + CSS + JS), listo para GitHub Pages.

- `index.html` — la página
- `js/config.js` — tus videos (enlaces de YouTube o .mp4): trabajos y reels
- `foto.jpg` — tu foto de la sección "Sobre mí" (puedes reemplazarla con el mismo nombre)
- `style.css`, `js/render.js`, `js/main.js` — estilos e interacciones

Publicación: Settings → Pages → Deploy from a branch → `main` / `(root)`.
